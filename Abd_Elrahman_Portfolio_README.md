## ✦ About This Project

This repository contains my personal **React + Vite portfolio website** — a digital space designed to present my background, technical skills, professional experience, education, certificates, selected projects, freelance platforms, and contact channels in one polished experience.

The portfolio is intentionally built around a **clean, cinematic, responsive interface** with subtle motion, bilingual support, theme switching, interactive project/certificate views, and performance-conscious image loading.

> **Design philosophy:** less noise, more hierarchy, meaningful motion, and every interaction should feel intentional.

## 🏗️ Run Locally

### 1. Clone

```bash
git clone https://github.com/Abd-Elrahman-Jehad/portfolio.git
cd portfolio/react-portfolio
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start development server

```bash
npm run dev
```

Vite will print the local development URL in the terminal, usually:

```text
http://localhost:5173
```

### 4. Build for production

```bash
npm run build
```

### 5. Preview the production build

```bash
npm run preview
```

## 🌐 Deployment

The project produces a static production build in:

```text
dist/
```

That build can be deployed to static hosting providers such as **GitHub Pages, Netlify, Vercel, or similar platforms**.

For a deployment workflow, the important command is:

```bash
npm run build
```

## 🖼️ Adding Projects & Certificates

The portfolio keeps project and certificate images outside the React component code.

### Projects

Place images inside:

```text
public/projects/
```

Then reference them from:

```text
src/data/projects.js
```

### Certificates

Place certificate images inside:

```text
public/certs/
```

Then manage their metadata in:

```text
src/data/certificates.js
```

This keeps the UI components clean and makes future content updates much easier.
